Step-by-Step Setup Guide to Run Program:
1. Open Terminal or Command Prompt
Step 1 : Navigate to the directory where your main.c file is located to Save :
Bash
cd path/to/your/project 
3. Compile the Program
Step 2  : Run the C compiler (GCC or Clang) to build the binary executable:
Bash
gcc main.c -o quiz_game
3. Run the Game
Step 3: Execute the compiled program directly in your terminal:
1. Linux / macOS: ./quiz_game
2. Windows (PowerShell / CMD): .\quiz_game.exe

   🎮 How to Play
1. Launch the executable file from your terminal/command prompt.

2. Read the displayed question and options carefully.

3.Type A, B, C, or D (or lowercase equivalents) and press Enter.

4. View instant feedback after each question.

5. Review your total score, percentage, and performance appraisal at the conclusion of the quiz.
