# Simple Quiz Game in C

A lightweight, terminal-based interactive multiple-choice quiz game written in C. This project was developed as part of **Software Development Lab I** at Pundra University of Science & Technology.

---

## 📌 Project Overview
Traditional study methods can often feel dry and lack engagement. The **Simple Quiz Game** is designed to provide students and learners with a fast, interactive way to test their recall accuracy directly inside the terminal. It evaluates answers in real-time, tallies points, and provides detailed performance feedback upon completion.

---

## ✨ Features
- **Multiple-Choice Questions:** Questions displayed with options (A, B, C, D).
- **Case-Insensitive Input:** Accepts both lowercase (`a`, `b`, `c`, `d`) and uppercase (`A`, `B`, `C`, `D`) inputs seamlessly.
- **Real-Time Feedback:** Instant evaluation after each answer.
- **Score & Percentage Calculation:** Tracks total points and calculates the exact score percentage.
- **Automated Performance Rating:** Generates personalized feedback based on the overall percentage achieved.

---
